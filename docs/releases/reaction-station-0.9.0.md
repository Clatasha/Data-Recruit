# Reaction Station 0.9.0

The first public Windows release of Reaction Station by Clatasha, built for YouTubers recording reactions to videos and online content.

## Recording and editing

- Redesigned recording overlay with customizable recorder and editor hotkeys.
- Separate desktop and microphone audio tracks with live volume controls.
- Media Library with thumbnails, search, reusable media, sticker imports and collapsible AI chat.
- Linked video/audio editing, track controls, snapping and scrolling timeline.
- Recording splits with camera layouts per section, trim previews and visual animation options.
- Removable user tracks, Media Bin deletion, smoother dragging and aligned appended video audio.
- MP4 exports with AAC audio quality options from 64 to 320 kbps.

## Download

Download **Reaction.Station.Setup.0.9.0.exe** and run it on Windows x64. The installer is unsigned. The blockmap and latest.yml files support updates; SHA256SUMS.txt verifies the installer.

This is an early release. macOS and Linux installers are not included.

## Validation

The installer is the unchanged artifact from [successful Windows build 37819844976](https://github.com/Clatasha/Reaction-Station/actions/runs/37819844976): native compilation, audio encoder checks, packaging inspection and packaged interface tests passed.

Real hardware capture, audible mixing and export testing were not performed by the release publisher because native desktop access is unavailable. These remain desktop checks; this release is marked as a prerelease.
